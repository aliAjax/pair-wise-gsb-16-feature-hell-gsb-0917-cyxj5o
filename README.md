# hxwl-01 听力验配记录

门店听力师的验配档案与听力曲线工作台

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5101

## 签发闭环

- 每份记录包含左右耳分频（250/500/1k/2k/4k/8k Hz）气导、骨导，以及左右耳言语识别率与增益
- 签发校验（任一不满足即不可签发）：
  - 缺必填项（患者姓名、分频气骨导、言语识别率、增益）或数值超范围
  - 同频骨导高于气导（生理上不可能成立）
  - 任一频率气骨导差超过 20dB 且未填写转诊建议
- 签发后数值冻结，表单只读；复调只能基于档案内最新版本新建带次数的修订（第 N 次修订），旧版本完整保留、可展开回看
- 记录与筛选条件持久化在 localStorage，刷新不丢失；多标签页同步，同 id 冲突时已签发历史优先
- 统计卡片、状态/分类筛选与记录列表全部由同一数据源派生，随记录状态实时联动；支持导出 JSON 摘要
